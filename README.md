# 🇮🇳 Utsav India – Festivals & Heritage

### ✨ One Nation, Countless Traditions

**Utsav India** is a responsive and visually appealing website that celebrates the vibrant festivals, rich traditions, and diverse cultural heritage of India. From the sparkling lights of Diwali to the colourful celebrations of Holi, the website showcases India's cultural beauty through an engaging user interface.

## 🌐 Live Demo

🔗 **Live Website:** https://festivalofindia-994jveo1b-shivani-319f.vercel.app/

## 📸 About the Project

Utsav India is a frontend web development project created to explore and showcase India's cultural diversity. It provides visitors with a simple and interactive way to discover popular Indian festivals, traditional art forms, and regional cultures.

## ✨ Features

- 🪔 **Festival Showcase:** Explore Diwali, Holi, Onam, and Durga Puja.
- 🎨 **Interactive Festival Cards:** Click on "Discover More" to learn about each festival.
- 💃 **Indian Traditions:** Discover classical dance, folk arts, regional cuisine, and handicrafts.
- 🗺️ **Regional Culture:** Explore the cultural diversity of North, South, East, and West India.
- 📱 **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- 🎯 **Smooth Navigation:** Navigate between sections using the navigation bar.
- ✨ **Hover Effects:** Enjoy interactive buttons, cards, and images.
- 🇮🇳 **Cultural Theme:** A warm colour palette inspired by India's traditions and heritage.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, responsive design, transitions, and hover effects.
- **JavaScript** – Interactive festival information cards using event listeners and DOM manipulation.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd Utsav-India
```

**3. Run the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
